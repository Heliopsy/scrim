# scrim chart: values reference

![Version: 0.3.0](https://img.shields.io/badge/Version-0.3.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.3.0](https://img.shields.io/badge/AppVersion-0.3.0-informational?style=flat-square)

Keeps secret values away from LLM providers while AI agents keep working

Generated by helm-docs from `deploy/helm/scrim/values.yaml` (the `# --` comments). Do not edit this
file: change values.yaml and run `deploy/helm/scrim/ci/verify.sh --generate`. The chart's guide is
[kubernetes.md](kubernetes.md), its README [deploy/helm/scrim/README.md](../deploy/helm/scrim/README.md).

## Install

```sh
helm install scrim oci://ghcr.io/heliopsy/charts/scrim --version 0.3.0 \
  -n scrim --create-namespace -f my-values.yaml
helm test scrim -n scrim
```

## Requirements

Kubernetes: `>=1.29.0-0`

Optional, depending on values: Kyverno 1.17 or later (`kyverno`, the `policies.kyverno.io/v1`
policy types), prometheus-operator CRDs
(`serviceMonitor`, `podMonitor`, `prometheusRule`), external-secrets (`secrets.externalSecrets`), a
CNI that enforces NetworkPolicies (`networkPolicy`), PostgreSQL (`postgres`), Reflector or
kubernetes-replicator (`global.replication`).
